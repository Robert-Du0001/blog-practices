## 怎么使用

1. 下载 / 克隆本仓库到本地；
2. 进入你想学习的实战文件夹，例如 `go-resume-web-practice/`；
3. 打开该文件夹内的 `README.md`，按里面的**环境要求、运行步骤、常见问题**操作即可。

每个实战文件夹都是**自包含**的：它的源码、资源、说明都在自己目录里，单独打开任何一个文件夹都能独立编译运行，不依赖仓库里的其他内容。

## 环境要求

不同实战用到的语言 / 工具不同，**具体见各自文件夹的 `README.md`**。通用前提：本地已安装对应语言的运行环境（如 Go、Node 等）。
