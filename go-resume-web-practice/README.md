# 个人简历网页服务实战 · 源码包

这是《个人简历网页服务实战》系列第 3 篇（收官篇）的配套可运行项目。

通过这个小项目，你可以：

- 把 HTML、CSS、图片**直接嵌进 Go 编译出来的程序里**，一个 `.exe` 文件就是全部；
- 让程序监听 `0.0.0.0`，使**同一个局域网**里的其他设备也能打开你的简历页面。

配套教程（含逐行讲解）请见博客对应文章页，或在公众号回复「简历服务」获取链接。

---

## 环境要求

- 安装 [Go](https://go.dev/dl/)，版本 **1.16 或更高**。
  本项目用到 `//go:embed` 指令，该特性从 Go 1.16 开始提供。
- 在终端执行 `go version` 可以查看当前版本。

---

## 目录结构

```
go-web-practice/
  main.go          # 入口：嵌入页面文件 + 启动 Web 服务
  go.mod           # Go 模块文件
  web/             # 页面文件（编译时会被嵌入，运行时不需要磁盘上的它）
    index.html     # 简历页面（浏览器访问 / 时自动打开它）
    style.css      # 页面样式
    avatar.jpg     # 头像图片
  README.md        # 就是本文件
```

> 注：`web/` 目录只在**编译期**被读入程序。编译完成后，把 `web` 文件夹删掉，
> 生成的可执行文件照样能正常提供页面——因为文件已经在程序里了。

## 怎么运行

在项目目录下，打开终端，二选一：

**方式一：直接运行（不用生成文件）**

```sh
go run main.go
```

**方式二：编译成可执行文件（方便发给别人）**

```sh
go build -o resume-server.exe      # Windows
# 或 macOS / Linux：go build -o resume-server .
```

然后双击 `resume-server.exe`，或在终端执行 `./resume-server`。

启动后，终端会打印两行提示，服务就跑起来了。

## 怎么访问

- **本机访问**：浏览器打开 `http://localhost:8080`
  （也可以写 `http://127.0.0.1:8080`）
- **同一局域网的其他设备**：浏览器打开 `http://<你的内网IP>:8080`

查看本机内网 IP：

- Windows：终端执行 `ipconfig`，找「IPv4 地址」，一般是 `192.168.x.x`
- macOS / Linux：执行 `ifconfig` 或 `ip addr`

> 注意是 `http://` + IP + 端口，不要漏掉端口 `:8080`，也不要写成 `https`。

## 常见问题

**Q：我在本机能打开，但同事/手机连不上？**
A：大概率是 Windows 防火墙拦了入站连接。程序首次运行时若弹出「是否允许访问网络」，
请勾选**专用网络**并允许；若当时点了取消，需到「Windows Defender 防火墙 → 允许应用通过防火墙」
里把 `resume-server.exe` 加进去。另外确认两台设备连的是**同一个 WiFi**（访客网络可能相互隔离）。

**Q：页面打开后头像裂了 / 样式没生效？**
A：本项目的页面已用 `embed` 嵌入程序，正常情况下不会出现。
若你改了代码，请确认 `//go:embed web` 这行紧贴变量声明上方、中间没有空行，
且 `web` 目录里确实包含 `index.html`、`style.css`、`avatar.jpg`。

**Q：端口 8080 被占用了怎么办？**
A：把 `main.go` 里的 `:8080` 改成别的端口，例如 `0.0.0.0:9000`，
然后访问地址也相应改成 `http://localhost:9000` 即可。

## 改成你自己的简历

打开 `web/index.html`，把里面的姓名、职位、联系方式、简介、技能、项目经历
换成你自己的内容；头像替换成你自己的图片并命名为 `avatar.jpg` 覆盖原文件，
重新 `go run` 或 `go build` 即可。
